# Inert request-body examples

These JSON documents show the Gemini Interactions request shape. They are not
scripts and are never executed by the installer or validator. Sources: S04-S08
in `../references/sources.json`. Inputs are synthetic.

`draft-request.json` is a short writing request. `extraction-request.json` includes
a nullable structured-output schema. `research-request.json` declares a search
tool. No example contains credentials or sends data on its own.

Before any actual use, check the current API reference, choose an approved client,
and confirm authorization for data transfer and charges. The included examples
are documentation-reviewed and JSON-validated, not live API-tested.
