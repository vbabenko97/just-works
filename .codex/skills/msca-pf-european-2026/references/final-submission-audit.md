# Final submission audit

Use this for the last review before portal submission. Verify against the latest official 2026 documents and the latest portal export.

## Gate A: eligibility/admissibility
- Correct PF topic/type: European Fellowship.
- PhD/defence requirement met by 9 September 2026.
- 8-year FTE research-experience rule checked, including any exclusions.
- 12-in-36-month mobility rule checked using residence/main-activity evidence and applicable exceptions.
- Resubmission restriction checked if relevant.
- One-proposal rule checked.
- Beneficiary/legal entity/country eligible.
- Duration within 12-24 months.

## Gate B: Part A
- Proposal title/acronym/abstract/keywords/descriptors match intended positioning.
- Descriptor order supports appropriate evaluator allocation.
- Researcher history has no unexplained gaps and dates reconcile with CV/B-2.
- Supervisor/host/department/legal entity data are current.
- Budget/duration/country/family allowance fields checked.
- Ethics and security answers match Part B narrative.
- Previous/similar proposal declaration correct.
- Latest portal export reviewed after the final edits.

## Gate C: Part B-1
- Exactly current required Sections 1-3.
- Maximum 10 counted pages after final rendering.
- No illegal page-margin/font tricks.
- No external hyperlinks used to expand content.
- No editorial markers, TODO/TBD, generator placeholders, comments, or working-language notes.
- References are legible and fit within the page count.
- Every objective maps to methodology and implementation.
- Claims in Impact do not exceed what the project can credibly enable.

## Gate D: Part B-2
- CV dates and content match Part A; unconventional/concurrent career paths explained where useful.
- CV approximately follows the template's indicative 5-page expectation unless there is a reason not to.
- Capacity table for beneficiary <=1 page; associated partner tables <=1/2 page each.
- Inter-relationships declared where the template requires them.
- Department-to-PIC legal/administrative relation supplied.
- Ethics/security extra sections used only when applicable.
- Green Charter section present and proportionate.
- Global-Fellowship-only letter omitted for an ordinary European Fellowship.
- No extra material attempting to smuggle B-1 content into uncapped B-2.
- Generative-AI disclosure/guidance checked against the current 2026 template/Guide.

## Gate E: evidence and consistency
- Host claims trace to host/CV/institutional/official sources.
- Publications/DOIs/titles/authorship verified where materially relied on.
- Dataset sizes, event counts, annual volumes, equipment, collaborations, grants, and supervisor metrics not guessed.
- Open factual questions have explicit owners and are not silently removed from a review copy.
- Latest source files, review copies, and portal fields point to one coherent version.

## Gate F: render and upload
- PDFs visually inspected page by page.
- Fonts embedded/legible; tables/figures not clipped; no accidental blank pages.
- B-1 page count checked on the exact upload artifact.
- File names and versions are unambiguous.
- Portal validation warnings resolved or consciously documented.

## Verdict
Return:
- **GREEN**: no known blocker; only ordinary residual judgement risk.
- **AMBER**: can potentially submit, but one or more material issues still require explicit acceptance/confirmation.
- **RED**: unresolved compliance, factual, versioning, or rendering issue makes submission unsafe.
