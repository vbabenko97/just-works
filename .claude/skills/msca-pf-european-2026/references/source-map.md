# Official source map: MSCA-PF 2026

Use official sources first. Dates and URLs below were checked during skill creation on 29 August 2026.

## Primary official sources

1. REA: MSCA Postdoctoral Fellowships 2026 call page
   https://rea.ec.europa.eu/funding-and-grants/horizon-europe-marie-sklodowska-curie-actions/msca-postdoctoral-fellowships_en
   Use for call dates, overall budget, process, and navigation to application resources.

2. REA: Horizon Europe MSCA - How to apply
   https://rea.ec.europa.eu/funding-and-grants/horizon-europe-marie-sklodowska-curie-actions/horizon-europe-msca-how-apply_en
   Use as the official index for the PF 2026 Guide for Applicants, General Annexes, proposal template, 6-step guide, common mistakes, evaluation forms, 8-year guidance/self-assessment, and keywords.

3. Horizon Europe MSCA Work Programme 2026-2027
   https://ec.europa.eu/info/funding-tenders/opportunities/docs/2021-2027/horizon/wp-call/2026-2027/wp-2-marie-sklodowska-curie-actions_horizon-2026-2027_en.pdf
   Controlling source for PF conditions, eligibility, mobility, duration, resubmission restriction, award criteria, thresholds, and unit contributions.

4. PF application form / Part B template, V5.0 dated 27 March 2026
   https://ec.europa.eu/info/funding-tenders/opportunities/docs/2021-2027/horizon/temp-form/af/af_he-msca-pf_en.pdf
   Use for exact Part A fields, Part B headings, page/format rules, CV content, capacity tables, inter-relationship declaration, and generative-AI guidance.

5. MSCA evaluation form, V2.2 dated 17 December 2025
   https://ec.europa.eu/info/funding-tenders/opportunities/docs/2021-2027/horizon/temp-form/ef/ef_he-msca_en.pdf
   Use for the evaluator scoring scale and criterion aspects. Cross-check weights/thresholds against the 2026 Work Programme.

6. European Commission MSCA work-programme index
   https://research-and-innovation.ec.europa.eu/funding/funding-opportunities/funding-programmes-and-open-calls/horizon-europe/marie-sklodowska-curie-actions_en

## Applicant guidance indexed by REA

The REA How-to-apply page links the current:
- Postdoctoral Fellowships Guide for Applicants 2026;
- Common mistakes in MSCA-PF proposal submission;
- 8-years research-experience calculation guidance;
- 8-years self-assessment tool;
- specific keywords;
- General Annexes.

Circabc links sometimes fail in automated browsing. If a direct link fails, return to the REA How-to-apply page rather than substituting an old unofficial document.

## Source hierarchy for application-specific questions

1. Work Programme / call conditions / Funding & Tenders portal.
2. Current 2026 application template and Guide for Applicants.
3. REA official guidance and official topic Q&As.
4. General Annexes and programme-level guidance.
5. NCP and host Research Service for case-specific administrative interpretation.
6. Peer-reviewed scientific/methodological sources for research design.
7. Everything else only as non-controlling context.
